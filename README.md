# Team Task Board

A lightweight task board for a small team. It runs in any modern browser and does
not require a build step or external dependencies.

## Run

Open `index.html` in a browser. Tasks are saved in that browser's local storage.

## Features

- Create and delete tasks, and move them through To do, In progress, and Done.
- Filter tasks by priority or search task titles, descriptions, and assignees.
- View live task counts and keep board data between visits.
